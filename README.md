# Docker - Projeto Simples

Aplicação web desenvolvida com HTML, CSS e JavaScript, executada pelo Apache HTTP Server em um contêiner Docker utilizando Docker Compose.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Apache HTTP Server
- Docker
- Docker Compose

## Como executar

1. Certifique-se de que o Docker Desktop esteja em execução.
2. Abra o terminal na pasta do projeto.
3. Execute o comando:

```bash
docker compose up -d
```

4. Acesse a aplicação no navegador:

http://localhost:8080

## Como parar

Para interromper e remover o contêiner criado pelo Compose, execute:

```bash
docker compose down
```
